Tk Console on Unix: Channel Transform Stepper

TIP 561 adds the console command to Unix. Follow a puts containing a \u21a9 escape from the script, through the channel's encoding and the transform's write method, to the text widget in the console window. Pick a script below: the first shows how tclIndex brings the command into existence; the others show output going to the terminal, then to the console, and back.

Notes for reviewers

    
Everything on this page is taken from consolecmd.tcl and consolecmd.impl in the tcl-console-unix repository (the same code as the tip-561-revised branch), run under Tcl/Tk 8.6.14 on Linux. The bytes and characters in the cells were measured by running that code with a probe on the transform's write; the page's self-check (?check=1) recomputes them in the browser. The Tcl core steps (substitution, unknown, the channel\u2019s encoding step) are not in these files; the page describes them and says so.

    
    
      
  • Locale. measured The decode line asks the channel which encoding it uses. In a UTF-8 locale that is right. With LANG=C on Tcl 8.6.14, fconfigure stdout -encoding reports iso8859-1 while the transform still receives UTF-8 bytes, so \u21a9 arrives in the widget as U+00E2 U+0086 U+00A9. The same code under C.UTF-8 shows the arrow. Worth checking on the Tcl 9.x target.
    • 
      
  • Interpreter gone. measured If the console interpreter is deleted while the transforms are still pushed, the next puts fails with console closed (the error branch in write) instead of printing anywhere.
    • 
      
  • Hide versus close. read from the code console hide pops the transforms and puts back the saved encodings; the window's close button runs Oc_RestorePuts, which pops them but does not restore encodings. Not tested.
    • 
      
  • Input. Only output is redirected. Stdin still comes from the terminal and the console accepts commands too, which is the question raised in the TIP discussion.
